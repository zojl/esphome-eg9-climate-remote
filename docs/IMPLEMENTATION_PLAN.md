# План реализации компонента ESPHome для EG9 Climate

Этот документ описывает функциональные требования к кастомному компоненту `eg9_climate` для ESPHome.

## 1. Пользовательский интерфейс и функционал в Home Assistant

Компонент должен предоставлять стандартный интерфейс климат-контроля в Home Assistant со следующими возможностями:

### 1.1. Режимы работы (`hvac_mode`)

На данном этапе поддерживаются два основных режима:
- **`Cool` (Охлаждение):** Основной режим работы.
- **`Off` (Выключено):** Полностью выключает кондиционер. Для этого режима используется одна заранее записанная команда "ВЫКЛ".

### 1.2. Выбор температуры (`target_temperature`)

- Пользователь должен иметь возможность выбирать целевую температуру.
- Диапазон температур: **от 16°C до 31°C**.
- Шаг изменения: 1°C.

### 1.3. Скорость вентилятора (`fan_mode`)

Поддерживаются следующие скорости:
- `Auto`
- `Slow` (Низкая)
- `Medium` (Средняя)
- `Fast` (Высокая)
- `Sleep` (Ночной режим)

### 1.4. Положение вертикальной шторки (`swing_mode`)

Поддерживаются следующие режимы для шторки:
- `Auto` (Автоматический выбор положения)
- `Top` (Самое верхнее положение)
- `Medium-Top` (Верхнее-среднее)
- `Medium` (Центральное)
- `Medium-Bottom` (Нижнее-среднее)
- `Bottom` (Самое нижнее положение)
- `Swing` (Режим постоянного качания)

## 2. Логика генерации ИК-команд

Реализация будет основана на подходе "словаря" (mapping), построенного на основе исчерпывающего набора дампов.

### 2.1. Сбор данных
- Пользователь предоставит ~560 дампов для режима "Охлаждение", покрывающих все комбинации 16 температур, 5 скоростей вентилятора и 7 положений шторки.

### 2.2. Создание словаря
- На основе дампов будет создан словарь `std::map` в C++ коде.
- **Ключ:** `std::vector<uint8_t>` из 7 байт (`B6`...`B12`), представляющий уникальную комбинацию настроек (Питание, Режим, Температура, и т.д.).
- **Значение:** `std::pair<uint8_t, uint8_t>`, содержащее байты `B13` и `B14` из самого первого встреченного замера для данной комбинации.

### 2.3. Алгоритм работы компонента
1.  **Для режима "Выключено":** Отправляется одна статичная, заранее записанная команда.
2.  **Для режима "Охлаждение":**
    - Компонент формирует ключ из 7 байт на основе выбранных пользователем настроек.
    - Осуществляется поиск этого ключа в словаре.
    - **Если ключ найден:** к первым 12 байтам команды добавляются байты `B13` и `B14` из словаря. Команда отправляется.
    - **Если ключ не найден:** отправка блокируется, в лог выводится предупреждение. Это означает, что для данной комбинации настроек не был предоставлен дамп.
